## 插件系统架构

在深入具体插件实现之前，我们先了解VChart插件系统的整体架构。VChart采用了基于接口的插件设计模式，所有插件都实现了共同的插件接口，并通过插件服务进行统一管理。

### 插件接口

VChart的插件接口定义了插件的生命周期和基本行为：

```typescript

  name: string
```

这个接口定义了插件的基本生命周期方法：

### 插件服务

插件服务是插件系统的核心，负责管理所有插件的注册、初始化和销毁：

```typescript
// packages/vchart/src/plugin/plugin-service.ts
export class PluginService implements IPluginService {
  private _plugins: Map<string, IPlugin> = new Map()

  register(plugin: IPlugin): void {
    if (this._plugins.has(plugin.name)) {
      return
    }
    this._plugins.set(plugin.name, plugin)
    plugin.onRegister?.(this)
  }

  unregister(name: string): void {
    const plugin = this._plugins.get(name)
    if (plugin) {
      plugin.onUnregister?.(this)
      this._plugins.delete(name)
    }
  }

  init(...args: any[]): void {
    this._plugins.forEach((plugin) => {
      plugin.onInit(this, ...args)
    })
  }

  destroy(): void {
    this._plugins.forEach((plugin) => {
      plugin.onDestroy()
    })
    this._plugins.clear()
  }

  getPlugin<T extends IPlugin>(name: string): T | undefined {
    return this._plugins.get(name) as T | undefined
  }
}
```

插件服务提供了以下核心功能：

- 注册和注销插件
- 初始化和销毁插件
- 获取特定插件实例

### 数值文本格式化

数值格式化是格式化插件的核心功能之一，它支持多种数值格式化模式：

```typescript
// packages/vchart/src/plugin/chart/formatter/formatter.ts
protected _formatSingleText(text: string | number, formatter: string): string | number {
  const isNumeric = numberSpecifierReg.test(formatter);
  if (isNumeric && this._numericFormatter) {
    // 内置的 formatter 逻辑，可以进行缓存性能优化
    let numericFormat;
    if (this._numericFormatterCache && this._numericSpecifier) {
      if (this._numericFormatterCache.get(formatter)) {
        numericFormat = this._numericFormatterCache.get(formatter);
      } else {
        numericFormat = this._numericSpecifier(formatter) as any;
        this._numericFormatterCache.set(formatter, numericFormat);
      }
      return numericFormat(Number(text));
    }
    return this._numericFormatter(formatter, Number(text));
  } else if (formatter.includes('%') && this._timeFormatter) {
    return this._timeFormatter(formatter, text);
  }
  return text;
}
```

这段代码的核心逻辑是：

1. 使用正则表达式`numberSpecifierReg`检测格式化字符串是否是数值格式
2. 如果是数值格式，则使用数值格式化器处理
3. 如果启用了缓存，会先检查缓存中是否已有对应的格式化函数
4. 如果缓存中没有，则创建新的格式化函数并缓存
5. 最后应用格式化函数处理数值

数值格式化支持的格式包括：

- **精度格式**：`.2f`（保留2位小数）
- **千分位格式**：`,`（添加千分位分隔符）
- **百分比格式**：`%`（显示为百分比）
- **科学计数法**：`e`（使用科学计数法）
- **自定义组合**：`.2%`（保留2位小数的百分比）

### 数据变量替换

模板格式化是格式化插件的另一个重要功能，它允许在格式化字符串中引用数据对象的字段：

```typescript
// packages/vchart/src/plugin/chart/formatter/formatter.ts
protected _formatText(text: string | number, formatter: string, datum?: any): string | number {
  if (!datum) {
    return this._formatSingleText(text, formatter);
  }

  // 处理模板格式化
  return formatter.replace(/\{([^}]+)\}/g, (match, key) => {
    const [field, format] = key.split(':');
    let value;

    // 支持嵌套字段访问，如 "data.value"
    if (field.includes('.')) {
      const keys = field.split('.');
      value = keys.reduce((obj, k) => (obj && obj[k] !== undefined ? obj[k] : undefined), datum);
    } else {
      value = datum[field];
    }

    if (value === undefined) {
      return match;
    }

    // 如果指定了格式，递归应用格式化
    if (format) {
      return this._formatSingleText(value, format);
    }

    return value;
  });
}
```

模板格式化的核心逻辑是：

1. 使用正则表达式`/\{([^}]+)\}/g`匹配大括号模板
2. 解析模板内容，提取字段名和格式说明（如果有）
3. 从数据对象中提取字段值
4. 如果指定了格式，递归应用格式化
5. 返回格式化后的值

模板格式化支持的功能包括：

- **简单字段引用**：`{sales}`
- **带格式的字段引用**：`{sales:.2f}`
- **嵌套字段引用**：`{data.value}`
- **组合格式**：`销售额：{sales:.2f}，增长率：{growth:.2%}`

### 媒体条件检查

当图表尺寸变化时，插件会检查所有媒体查询条件，并应用匹配的动作：

```typescript
// packages/vchart/src/plugin/chart/media-query/media-query.ts
protected _onResize = () => {
  this._checkMediaQueries();
};

protected _checkMediaQueries() {
  if (!this._mediaQueries.length) {
    return;
  }

  const { width, height } = this._chart.getSize();
  const aspectRatio = width / height;

  let specChanged = false;
  const newActiveQueries = new Set<IMediaQuery>();

  // 检查每个媒体查询
  this._mediaQueries.forEach(query => {
    const { condition, actions } = query;
    const matched = condition.match({
      width,
      height,
      aspectRatio
    });

    if (matched) {
      newActiveQueries.add(query);
      if (!this._activeQueries.has(query)) {
        // 新激活的查询，应用动作
        actions.forEach(action => {
          action.apply(this._chart.getSpec());
        });
        specChanged = true;
      }
    } else if (this._activeQueries.has(query)) {
      // 取消激活的查询，恢复原始配置
      specChanged = true;
    }
  });

  // 如果活动查询发生变化，更新图表
  if (specChanged) {
    this._activeQueries = newActiveQueries;
    this._updateChartSpec();
  }
}

protected _updateChartSpec() {
  // 从原始配置开始
  const newSpec = cloneDeep(this._originalSpec);

  // 应用所有活动查询的动作
  this._activeQueries.forEach(query => {
    query.actions.forEach(action => {
      action.apply(newSpec);
    });
  });

  // 更新图表配置
  this._chart.updateSpec(newSpec);
}
```

### 媒体条件实现

媒体条件类负责判断当前尺寸是否匹配查询条件：

```typescript
// packages/vchart/src/plugin/chart/media-query/condition.ts
export class MediaCondition implements IMediaCondition {
  protected _minWidth?: number
  protected _maxWidth?: number
  protected _minHeight?: number
  protected _maxHeight?: number
  protected _minAspectRatio?: number
  protected _maxAspectRatio?: number

  constructor(query: IMediaQuery['query']) {
    this._minWidth = query.minWidth
    this._maxWidth = query.maxWidth
    this._minHeight = query.minHeight
    this._maxHeight = query.maxHeight
    this._minAspectRatio = query.minAspectRatio
    this._maxAspectRatio = query.maxAspectRatio
  }

  match(size: { width: number, height: number, aspectRatio: number }): boolean {
    const { width, height, aspectRatio } = size

    // 检查宽度条件
    if (this._minWidth !== undefined && width < this._minWidth) {
      return false
    }
    if (this._maxWidth !== undefined && width > this._maxWidth) {
      return false
    }

    // 检查高度条件
    if (this._minHeight !== undefined && height < this._minHeight) {
      return false
    }
    if (this._maxHeight !== undefined && height > this._maxHeight) {
      return false
    }

    // 检查宽高比条件
    if (this._minAspectRatio !== undefined && aspectRatio < this._minAspectRatio) {
      return false
    }
    if (this._maxAspectRatio !== undefined && aspectRatio > this._maxAspectRatio) {
      return false
    }

    return true
  }
}
```

### 媒体动作实现

媒体动作类负责在条件匹配时修改图表配置：

```typescript
// packages/vchart/src/plugin/chart/media-query/action.ts
export class MediaAction implements IMediaAction {
  protected _filterType: string
  protected _filter: any[]
  protected _spec: any

  constructor(action: IMediaActionConfig) {
    this._filterType = action.filterType
    this._filter = Array.isArray(action.filter) ? action.filter : [action.filter]
    this._spec = action.spec || {}
  }

  apply(chartSpec: any): void {
    // 根据过滤类型获取目标配置
    const target = this._getTargetByType(chartSpec)
    if (!target) {
      return
    }

    // 应用配置更改
    if (Array.isArray(target)) {
      // 处理数组类型的配置
      target.forEach((item) => {
        if (this._matchFilter(item)) {
          Object.assign(item, this._spec)
        }
      })
    }
    else {
      // 处理对象类型的配置
      Object.assign(target, this._spec)
    }
  }

  protected _getTargetByType(chartSpec: any): any {
    switch (this._filterType) {
      case 'chart':
        return chartSpec
      case 'title':
        return chartSpec.title
      case 'legends':
        return chartSpec.legends
      case 'axes':
        return chartSpec.axes
      // 其他类型...
      default:
        return null
    }
  }

  protected _matchFilter(item: any): boolean {
    if (!this._filter.length) {
      return true
    }

    return this._filter.some((filter) => {
      return Object.keys(filter).every((key) => {
        return item[key] === filter[key]
      })
    })
  }
}
```
